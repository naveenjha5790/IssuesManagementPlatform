IssuesManagementPlatform
This is an issues Management platform where a user can raise an issue which happens in real life and which manager will assign to technician to solve it. This project is designed for a normal resident in a society. 

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You need to have **Node.js** installed on your computer. (Recommended: version 18)

### 🛠️ Installation

1. **Clone the repository** (if using Git):
   git clone https://github.com
   cd your-repo-name
   ```

2. **Install the dependencies**:
   npm install
   ```

## 💻 Usage

To start the project in development mode, run:
npm start
```
Following is an .env.example for reference
JWT_SECRET=your_secret_jwt_token
DATABASE_URL="PostgreSQL://username:yourpassword@localhost:portNo/dbName?schema=public"
