# Issues Management Platform

A fast, modern user interface built with React and powered by Vite. It provides users an UI to login and signup to raise tickets, check status for their ticket, history etc.

## 🚀 Getting Started

Follow these steps to set up and run the frontend development server on your local machine.

### Prerequisites

Ensure you have **Node.js** (which includes `npm`) installed:(Recommended version:18)

### 🛠️ Installation

1. Open your terminal in the project's root folder.
2. Install all the project dependencies by running:
   ```
   npm install
   ```

## 💻 Available Scripts

In the project directory, you can run the following commands:

### `npm run dev`
Runs the app in development mode.  
Open [http://localhost:5173](http://localhost:5173) to view it in your browser. The page will hot-reload automatically when you save changes to your code.

### `npm run build`
Builds the app for production to the `dist` folder.  
It compiles and minifies your assets so they are ready to be deployed to hosting platforms like Vercel, Netlify, or AWS.

### `npm run preview`
Locally previews the production build created by the build script to test it before deploying.
